# Taschenrechner – Python & GitHub Actions CI/CD

Dieses Projekt implementiert einen einfachen Taschenrechner in Python mit zugehörigen Unit-Tests und einer vollständigen CI/CD-Pipeline auf GitHub Actions.  
Die Pipeline führt Tests aus, erstellt ein Build-Artefakt, schützt das Deployment über ein Environment und erzeugt automatisch ein Release.
